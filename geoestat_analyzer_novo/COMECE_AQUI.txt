🚀 COMO USAR EM 3 PASSOS
════════════════════════════════════════════════════════════════════════════

1️⃣  INSTALE DEPENDÊNCIAS (primeira vez)
    
    pip install -r configuracao/requirements.txt

2️⃣  COLOQUE ARQUIVO

    Cole seu Excel/CSV em:  dados/entrada/seu_arquivo.xlsx

3️⃣  EXECUTE

    python executavel/principal.py

    ✓ Arquivo será analisado automaticamente
    ✓ Relatório PDF será criado em dados/saida/


📊 O QUE ACONTECE AUTOMATICAMENTE
════════════════════════════════════════════════════════════════════════════

Quando você executa principal.py:

✓ Detecta coordenadas (X, Y, Lat, Lon)
✓ Identifica variáveis numéricas (até 6)
✓ Calcula estatísticas (média, mediana, desvio padrão)
✓ CALCULA COEFICIENTE DE VARIAÇÃO (CV%)
✓ DESTACA EM VERMELHO variáveis com CV > 100%
✓ Converte coordenadas para WGS84 (EPSG:4326)
✓ Gera relatório PDF profissional (7 páginas)

Tudo em ~15-20 segundos!
