================================================================================
                           🔧 SISTEMA DE REFERÊNCIA
================================================================================

O sistema detectará automaticamente as coordenadas e usará por padrão:

    EPSG:32733 - UTM Zona 23 Sul (Padrão para o Brasil)

Se seu arquivo usar um CRS diferente, você pode:
1. Converter antes de usar este sistema
2. OU editar o arquivo analyzer.py e mudar a linha 22:
   DEFAULT_CRS = "EPSG:[seu_codigo]"

Códigos EPSG comuns:
- EPSG:32733 - UTM 23S (Brasil - Padrão)
- EPSG:32722 - UTM 22S (Brasil - Regiões de transição)  
- EPSG:4674  - SIRGAS 2000 (Brasil - Lat/Lon)
- EPSG:4326  - WGS84 (Global - Lat/Lon)

COEFICIENTE DE VARIAÇÃO (CV%)
────────────────────────────────────────────────────────────────────────────

O sistema calcula automaticamente o CV% para cada variável:

   CV% = (Desvio Padrão / Média) × 100

Interpretação:
   • CV < 15%     : Baixa variabilidade
   • CV 15-30%    : Variabilidade moderada
   • CV 30-100%   : Alta variabilidade
   • CV > 100%    : ALERTA - Heterogeneidade extrema ⚠️

Variáveis com CV > 100% são destacadas em VERMELHO no relatório PDF!

CONVERSÃO AUTOMÁTICA DE COORDENADAS
────────────────────────────────────────────────────────────────────────────

Entrada: EPSG:32733 (UTM 23S) - Coordenadas em metros
Saída:   EPSG:4326 (WGS84) - Coordenadas em graus decimais

Benefícios:
   ✓ Compatível com Google Maps
   ✓ Compatível com OpenStreetMap (OSM)
   ✓ Padrão internacional (latitude, longitude)
   ✓ Pronto para bancos de dados geoespaciais

As coordenadas convertidas aparecem na página "Georreferenciamento" do PDF.
