# ✨ ANÁLISE GEOESTATÍSTICA - MODO FÁCIL

## 🎯 Tudo em 3 Passos Simples

### ✅ Passo 1: Abra o PowerShell

```
Pressione: Windows + R
Digite: powershell
Pressione: Enter
```

### ✅ Passo 2: Navegue para a Pasta

```powershell
cd "C:\Users\seu_usuario\OneDrive\Documentos\Vscode\.github\Aldino2"
```

(Copie o comando exato do seu computador)

### ✅ Passo 3: Execute o Programa

```powershell
python executar.py
```

## 🧭 Onde Está a Versão Oficial

- O arquivo de entrada oficial é [executar.py](executar.py).
- A implementação ativa fica em [geoestat_analyzer_novo/](geoestat_analyzer_novo/).
- A pasta [geoestat_analyzer/](geoestat_analyzer/) é legada e existe para compatibilidade histórica.

## 🖱️ O que Acontece Depois

Um **explorador de arquivos abrirá na sua tela**:

- Procure por um arquivo `.xlsx` (Excel) ou `.csv` (dados)
- **Clique no arquivo** que deseja analisar
- **Clique em "Abrir"**

## ⏳ Aguarde a Análise

O programa vai:
1. Carregar seu arquivo
2. Detectar coordenadas automaticamente
3. Calcular análises geoespaciais
4. Gerar mapas em alta definição
5. Criar gráficos e visualizações
6. **Abrir PDF automaticamente no seu navegador** ✨

## 📥 Salvar o PDF

Quando o PDF abrir no navegador:
- Clique no ícone de **download** (↓)
- Escolha onde quer salvar
- **Pronto!** Seu relatório está pronto

## ❓ Dúvidas Frequentes

**P: Por que o explorador não mostra meus arquivos?**  
R: Certifique-se que está procurando por `.xlsx` ou `.csv`. Outros tipos de arquivo não aparecem.

**P: Posso analisar qualquer arquivo do meu computador?**  
R: SIM! O explorador deixa você procurar em qualquer pasta. Basta ter colunas com números e coordenadas.

**P: Quanto tempo demora?**  
R: De 30 segundos a 2 minutos, dependendo do tamanho do arquivo.

**P: Posso rodar várias análises?**  
R: SIM! Basta rodar `python executar.py` novamente!
