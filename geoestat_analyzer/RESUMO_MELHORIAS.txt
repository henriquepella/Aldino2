┃ #1 - COEFICIENTE DE VARIAÇÃO (CV%) AUTOMÁTICO                             ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

📊 O QUE FOI ADICIONADO:
   • Cálculo automático de CV% para cada variável numérica
   • Fórmula: CV(%) = (Desvio Padrão / Média) × 100
   • Identificação de heterogeneidade espacial

📈 INTERPRETAÇÃO DO CV%:
   
   CV < 15%      → ✅ Baixa variabilidade (normal)
   CV 15-30%     → ✅ Variabilidade moderada
   CV 30-100%    → ⚠️  Alta variabilidade
   CV > 100%     → 🚨 HETEROGENEIDADE EXTREMA (destacado em vermelho!)

💡 COMO USAR ESSAS INFORMAÇÕES:
   
   • CV > 100%: Indica que a variável tem muita variação local
   • Requer análise geoestatística especializada (kriging adaptativo, etc.)
   • Possível presença de múltiplos domínios geológicos
   • Validar dados para outliers ou erros de medição

┃ #2 - CONVERSÃO AUTOMÁTICA DE COORDENADAS PARA WGS84                       ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

🌍 O QUE FOI ADICIONADO:
   • Transformação automática de coordenadas
   • De: EPSG:32733 (UTM - metros locals)
   • Para: EPSG:4326 (WGS84 - graus decimais globais)
   • Compatível com Google Maps, OpenStreetMap, SIG online

✅ BENEFÍCIOS:
   
   ✓ Compatibilidade Global: Funciona em qualquer plataforma geoespacial
   ✓ Padrão Internacional: WGS84 é o padrão de facto mundial
   ✓ Google Maps Ready: Copy/paste coordenadas direto no Google Maps
   ✓ SIG Online: Compatível com QGIS Web, ArcGIS Online, etc.
   ✓ Bancos de Dados: PostGIS, MongoDB Geospatial, etc. entendem WGS84

📍 EXEMPLO DE CONVERSÃO:
   
   ENTRADA (UTM 23S):
   X = 654500.50 metros (Easting)
   Y = 7055000.25 metros (Northing)
   CRS: EPSG:32733
   
   ⬇️  AUTOMÁTICO  ⬇️
   
   SAÍDA (WGS84):
   Longitude = 16.557129°
   Latitude = -26.615131°
   CRS: EPSG:4326
   
   Para Google Maps, copie: -26.615131, 16.557129

📄 NO RELATÓRIO PDF:
   
   NOVA Página: "Georreferenciamento" (página 5)
   
   Contém:
   • Sistema de Referência original
   • Sistema de Referência destino (WGS84)
   • Estatísticas das coordenadas convertidas
   • Centro aproximado em graus decimais
   • Formato pronto para Google Maps/OSM

🔧 ALTERAR O CRS PADRÃO:
   
   Se precisar usar outro CRS (ex: EPSG:32722 para UTM 22S):
   
   1. Abra: analyzer.py
   2. Vá para a linha 22
   3. Altere: DEFAULT_CRS = "EPSG:32733"
   4. Para: DEFAULT_CRS = "EPSG:32722"
   
   CRS Comuns:
   • EPSG:32733 - UTM 23S (Brasil padrão)
   • EPSG:32722 - UTM 22S (Brasil norte)
   • EPSG:4674  - SIRGAS 2000 (Brasil Lat/Lon)
   • EPSG:4326 - WGS84 (Global)
