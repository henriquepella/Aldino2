## 🚀 Use Assim

### 1. Instale dependências (primeira vez):
```bash
pip install -r configuracao/requirements.txt
```

### 2. Coloque seu arquivo em:
```
dados/entrada/seu_arquivo.xlsx
```

### 3. Execute análise:
```bash
python executavel/principal.py
```

### 4. Relatório em:
```
dados/saida/Relatorio_Geoestat_*.pdf
```

## 📚 Módulos Principais

### `analise/analisador.py`
- **Classe:** `AnalisadorGeo`
- **Funções:**
  - `detectar_coordenadas()` - Encontra X, Y, Lat, Lon automaticamente
  - `detectar_variaveis_numericas()` - Identifica variáveis para análise
  - `calcular_estatisticas()` - Calcula média, mediana, CV%, etc
  - `converter_coordenadas_wgs84()` - Transforma para WGS84
  - `analisar()` - Executa pipeline completa

### `analise/gerador_relatorio.py`
- **Classe:** `GeradorRelatorio`
- **Funções:**
  - `_adicionar_pagina_titulo()` - Página 1
  - `_adicionar_pagina_descricao()` - Página 2
  - `_adicionar_pagina_estatisticas()` - Página 3 (tabela com CV%)
  - `_adicionar_pagina_visualizacao()` - Página 4 (gráficos)
  - `_adicionar_pagina_georreferenciamento()` - Página 5 (WGS84)
  - `_adicionar_pagina_analise_espacial()` - Página 6 (mapas)
  - `_adicionar_pagina_conclusoes()` - Página 7
  - `gerar()` - Cria PDF com todas as páginas

### `utilitarios/criar_dados_exemplo.py`
- Função: `criar_dados_exemplo()`
- Gera arquivo Excel com 250 amostras e 6 variáveis

### `executavel/principal.py`
- Script principal que:
  1. Procura arquivo em `dados/entrada/`
  2. Executa análise com `AnalisadorGeo`
  3. Gera relatório com `GeradorRelatorio`
